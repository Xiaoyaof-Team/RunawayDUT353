逃离“踪遗”
## 特别说明
**项目内容里不包含Build文件夹，需要自行拉取**
## 游戏玩法
1. 通过"A"/"←"、"D"/"→"来控制角色移动。
2. 按E与物体交互。
3. 按W与门或楼梯交互。
4. 指针指到11-2时，场景有一定几率变异，此时请走右侧楼梯，否则请走左侧楼梯。
5. 在游玩过程中可能遇到镜中人与您对话，请按空格键与其交互，交互完毕后正常按E键退出。
6. Esc键可暂停/返回。
7. 玩家正确到达时钟指向1点的楼层并从大门逃出生天为通关。

## 项目说明
本项目于2月26日发布v1.0版本，按计划时间结项。
### 游戏性质
类《13F》，2D恐怖闯关游戏。
### 技术特点
1. 技术新：使用目前较新的SFML3作为基础图形库。
2. 模块化：不同功能完全分区，每个部分状态控制几乎采用状态机，项目结构清晰易懂。异常管理部分将场景与事件处理几乎完全拆分，代码复用度高。
3. 规范好：对复杂部分添加简单注释，各功能处添加简要功能说明，变量命名规范，代码分区但命名规则不变，代码一致易读。
4. 细节精：几乎处理了所有非法行为，比如调节窗口导致画面比例问题，事件处理时非法按键的返回等。
### 开发工具
Visual Studio 2022+SMFL库。
### 项目灵感
项目起初灵感来自于综一教学楼353教室由于位置特殊导致很多人初次寻找困难的调侃，因此设定位置为教学楼，后由于AI生成素材的局限进行了大量简化。
### 游戏背景
在晚上，主角在综一惊醒，发现里面空无一人，主角发现宿舍马上熄灯，想赶紧回去，却发现教学楼似乎不太一样了。
### 主要功能
1. 玩家操作人物，判断现场景是否存在异常，根据判断选择对应楼梯。共计有10个关卡，时钟会从12倒数，如果判断错误，时钟会回到12，判断正确，时钟会倒退一小时，当时钟指向1时，出口便会出现。
2. 游戏进行了基础的优化操作，游戏内部在视角控制方面添加了边缘检测，在靠近场景边缘时不会再以人物为中心，使得视野不会看见背景边上的黑边，添加了实时晃动，使画面更有动感，同时视野有跟随鼠标移动的动效，增加了沉浸感。
3. 游戏提供了充分自由度，设置内可以设置声音，是否全屏，视角控制等个性化内容，玩家可以需要适时改变。同时对基本窗口进行了优化，使得画面不会出现变形问题。

### 后续改进
游戏后期进行了一点简单的改进，比如加入了各种动效，使游戏整体更为流畅，但依旧有处理不到位的地方，如没有关卡过度，导致部分异常场景在生成时存在卡顿。由于时间和个人能力的不足，异常几乎都很简单，没有过分复杂的逻辑，缺少素材使得很多地方难以美化处理。
### AI声明
本项目实现过程中有AI的帮助。
#### AI生成图片
本游戏贴图原稿来自AI生成，但由人类进行美化、拼凑合成。
#### AI提供思路：
很多时候，AI可以为我们想实现但没想法的功能提供基础的思路。比如在菜单界面的文字回弹动画的制作过程中，原来的思路十分繁琐，通过AI询问互动后才了解到原来有专门的函数实现这个功能。AI也许不会生成最让人满意的代码，但是AI的知识面很广，很多时候和AI聊聊会知道很多自己前所未闻的知识。
#### AI验证猜想
当一个大想法时，会优先去问问AI怎么想。一方面是为了看看AI是不是会提供更好的思路，有时也能很有效地把错误方法扼杀在摇篮中，避免后续的麻烦，提高代码编写的效率。比如在思考异常管理办法的时候，就向AI询问多次方案可行性，因为异常是整个游戏的重心所在，不能因为现在方法的问题对以后造成几乎不可逆的漏洞。
#### AI寻找问题
现在的AI有着不差的agent能力，很多时候AI找问题的能力远高于人力，很多时候，即使很明确问题的来源，也不想从复杂的代码块中寻找那个出问题的代码在哪，也可以简简单单交给AI处理，这同样加快了代码编写的效率。
